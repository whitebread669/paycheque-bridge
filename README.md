# The Paycheque Bridge

*Your paycheque is already paying your future self — you've just never been shown.*

**Live demo: [calgarymoney.com](https://calgarymoney.com)** · built in Cursor from [SPEC.md](./SPEC.md) for the Cursor Hackathon

A [calgarymoney.com](https://calgarymoney.com) project built for the Cursor Hackathon, based on the retirement writing of Jordan Defazio ([More Than Money Radio](https://www.morethanmoneyradio.com/retirement-blog) and the [Popowich Karmali Advisory Group](https://woodgundyadvisors.cibc.com/Popowich-Karmali-Group/blog)).

A single-page interactive experience that follows one $5,000 paycheque across five acts: the bleak retirement stub you get by default, the pay stub that decodes itself, four competing buckets (Income, Growth, Health, Legacy), feedback in retirement *days* instead of dollars, and the rebuilt retirement paycheque you end up with.

**Start here: [SPEC.md](./SPEC.md)** — the full build spec: screens, state model, formulas, CPP/OAS defaults, canned data, and the Cursor kickoff prompt.
